# Task Manager

Простое desktop-приложение для управления задачами (Python + Tkinter).

## Запуск
1. Установите Python 3.x.
2. Запустите `gui.py`:
   ```
   python gui.py
   ```
3. Добавляйте задачи через форму, удаляйте выбором в списке.

## Функциональность
- Добавление/удаление задач.
- Автосохранение в JSON-файл (`tasks.json`) и загрузка при запуске.

## Структура проекта
- `classes.py` — классы `Task` (отдельная задача) и `TaskManager` (управление списком задач, файловые операции).
- `gui.py` — графический интерфейс на Tkinter (поля ввода, кнопки, список задач).
- `tasks.json` — файл хранения задач.

## Использование
1. Введите название задачи, описание и срок выполнения в формате `ГГГГ-ММ-ДД`.
2. Нажмите «Добавить» — задача появится в списке и сохранится в файл.
3. Выделите задачу в списке и нажмите «Удалить», чтобы удалить её.
